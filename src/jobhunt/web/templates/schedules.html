How it behaves

  • A scheduled run is a normal run: watch or stop it on Runs.
  • Only one run at a time. With wait if busy, a schedule retries every 10 minutes for up to 2 hours.
  • Catch up: if the PC was off or asleep at the scheduled time, the run starts when the server is back (within 12 hours).
  • Fetch-only runs leave jobs in Waiting to score ({{ waiting }} now).
  • Scoring uses the model picked in the top bar at the time the run scores.
