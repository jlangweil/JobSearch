Job alert emails (LinkedIn, Indeed and others)

{{ 'on' if email.enabled else 'off' }} {{ 'mailbox saved' if email.account_set else 'not set up' }}

LinkedIn and Indeed have no API for searching jobs, and their terms forbid crawling them — but the alert emails they send you are yours. Set up job alerts on those sites, and jobhunt reads that mailbox read-only: it never deletes, moves, replies or marks anything as read, and only opens messages from the senders (or in the folder) below. Alerts carry a title, company, location and link but no description, so imported jobs wait in Waiting to score with a Paste the posting action; their links often lead to the employer's own careers page, which Add a job can read in full.

Gmail: turn on 2-step verification, create an app password (myaccount.google.com → Security → App passwords) and paste it below; a label such as JobAlerts with a filter keeps jobhunt away from the rest of your mail. An app password grants access to the whole account, so a dedicated address (with alerts forwarded to it) is the tightest option.

Network access

{{ 'other devices on your network' if network.lan else 'this PC only' }}

Off by default: the app listens on 127.0.0.1, which nothing else can reach. Switch this on to open it from a laptop or phone on the same network. Traffic is plain HTTP, so keep it to a network you trust and never forward the port through your router.

Any username works; the password is what's checked. It is saved to .env as WEB_PASSWORD.

On the laptop, open {{ network.url }}{% if network.ips | length > 1 %} (also {{ network.ips[1:] | join(', ') }}){% endif %}
