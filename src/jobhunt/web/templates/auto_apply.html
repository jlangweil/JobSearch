Auto-apply beta

Opens a real browser, signs in to the Workday site with the account you save below, uploads the tailored resume, types your work history in from the fact bank (rather than trusting Workday's resume parser), and answers the standard questions from your profile. It stops on the Review page{% if cfg.auto_apply.auto_submit %} unless auto-submit is on — it is on, so runs will submit{% endif %}. It never solves a captcha and never invents an answer: anything it does not know becomes an open question below.

Workday sign-ins

Each Workday tenant keeps its own candidate account. Use * as the site to reuse one email everywhere. On a site you have never applied to, a run signs in with that email — and if there is no account yet it creates one, saves it here with its own generated password, and reads the site's verification email from the mailbox you set up for job alerts. {% if store_mode == 'plain' %}Passwords are stored as typed and shown below, so a password jobhunt generated for a site can be read and used by hand. Anything that can read data/jobhunt.db — or reach this page on your network — can read them too. Switch to encrypted storage on Settings → Auto-apply. {% else %}Passwords are encrypted with Windows DPAPI for your login, so a copied database yields nothing.{% endif %}
